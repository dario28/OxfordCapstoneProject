# References Folder

This folder is the working library for standards, regulations, and guidance used across the capstone.

## How To Use It
- Put source PDFs, exported web pages, or notes into the relevant subfolder.
- Use each folder `README.md` to capture:
- why the reference matters in this scenario
- which systems it applies to
- which risks or controls it supports
- any key clauses, articles, or functions we want to cite

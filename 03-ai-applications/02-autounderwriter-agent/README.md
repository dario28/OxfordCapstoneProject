# AutoUnderwriter Agent

## Scenario Role
Agentic underwriting workflow combining multiple models and tools, with elevated `autonomy`, `dependency`, and `emergent capability` risk.

## Key Framework Anchors
- `NIST AI RMF`
- `MITRE ATLAS`
- `OWASP LLM Top 10`
- `ISO/IEC 42001`

## Drafting Focus
- Agent workflow boundaries and decision points
- Tool-use permissions and approvals
- Human-in-the-loop checkpoints for underwriting decisions
- Data inputs, explainability, and audit trail requirements
- Monitoring for drift, unsafe tool use, and policy breaches

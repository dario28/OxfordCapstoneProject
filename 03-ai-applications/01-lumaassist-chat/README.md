# LumaAssist Chat

## Scenario Role
LLM-based customer assistant directly exposed to `prompt injection`, `data leakage`, and `evaluation risks`.

## Key Framework Anchors
- `OWASP LLM Top 10`
- `MITRE ATLAS`
- `NIST CSF`

## Drafting Focus
- Customer-facing usage pattern and escalation to humans
- Prompt routing, grounding, and output controls
- Sensitive-data exposure and retention boundaries
- Evaluation approach and quality assurance
- Monitoring for misuse, leakage, and prompt abuse

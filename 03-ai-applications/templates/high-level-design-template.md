# One-Page HLD Template

## 1. System Overview
- System name
- Business purpose
- Decision criticality
- Customer-facing, internal, or third-party
- Executive owner
- Technical owner

## 2. AI Pattern
- Model type or provider
- Foundation model, predictive model, agentic workflow, or third-party model
- Human-in-the-loop design
- Relevant substrate properties: opacity, autonomy, dependency, drift, scale asymmetry

## 3. Core Workflow
- Trigger or entry point
- Key processing steps
- Decision or output path
- Manual override or escalation path

## 4. Lifecycle View
- Design risks and controls
- Data risks and controls
- Develop risks and controls
- Deploy risks and controls
- Monitor risks and controls

## 5. Data And Integrations
- Input data
- Output data
- Sensitive data classes
- Internal systems
- External APIs, vendors, or data suppliers
- Cross-border data flows

## 6. Hosting And Operations
- `test` account pattern
- `production` account pattern
- Identity and access model
- Logging and evidence retention
- Monitoring and drift controls

## 7. Enterprise Risk Lenses
- Governance lens considerations
- Operational lens considerations
- Cyber lens considerations

## 8. Standards And Evidence
- Primary standards or regulations
- Due-diligence artefacts to request
- Audit or conformity evidence expected

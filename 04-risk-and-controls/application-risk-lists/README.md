# Application Risk Lists

These files capture a broader set of AI risks per application before we compress them into the formal `10–12` risk register extract required for Deliverable B.

## Purpose
- Generate realistic risks from the actual HLDs
- Preserve system-specific detail
- Help us choose the top board-level risks later
